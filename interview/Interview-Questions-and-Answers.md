# Wireshark Interview Questions and Answers

### 1. What is Wireshark?
Wireshark is a network protocol analyzer used to capture and inspect network packets.

### 2. What is a packet?
A packet is a small unit of data transmitted over a network.

### 3. How do you filter packets in Wireshark?
We use display filters such as `dns`, `tcp`, `udp`, and `tls`.

### 4. What is the difference between TCP and UDP?
TCP provides reliable and ordered delivery. UDP is connectionless and does not guarantee delivery or packet order.

### 5. What is a DNS query packet?
A DNS query packet is a request asking a DNS server to find the IP address associated with a domain name.

### 6. How does packet capture help with troubleshooting?
It helps identify communication problems, DNS failures, retransmissions, and suspicious network activity.

### 7. What is a network protocol?
A network protocol is a set of rules that devices follow to communicate.

### 8. Can Wireshark decrypt encrypted traffic?
Wireshark cannot automatically decrypt encrypted traffic. Suitable session keys or other decryption information are needed.
