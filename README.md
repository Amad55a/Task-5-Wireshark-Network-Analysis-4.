# Task 5: Capture and Analyze Network Traffic Using Wireshark

## Objective
To capture live network traffic and identify common network protocols using Wireshark.

## Tool Used
- Wireshark
- Npcap

## Work Completed
- Captured network packets from my active network interface.
- Generated network traffic by browsing a website.
- Applied display filters to examine DNS, TCP, and other captured protocols.
- Inspected packet details, including source, destination, and protocol information.
- Saved the packet capture for analysis.

## Files
- `captures/Task5_Network_Capture.pcap` — packet capture file.
- `screenshots/` — screenshots showing the capture and protocol filters.
- `report/` — network analysis report.

## What I Learned
I learned how to capture network traffic, use Wireshark display filters, inspect packet details, and understand basic network protocols such as DNS and TCP.

## Conclusion
This task provided practical experience in network packet capture and protocol analysis using Wireshark.
